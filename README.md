## 🇺🇸 English Installation

### Method 1: Vencord Online Import (Recommended — 1 Click)
1. Open Discord with Vencord installed.
2. Go to **User Settings** ➔ **Themes** (under Vencord section).
3. Under **Theme Links**, paste the direct link:
   ```text
   https://raw.githubusercontent.com/Fameboyq/vencord-violet-theme/main/fameboyq-violet.theme.css
   ```
4. Press Enter. The theme will apply immediately and receive automatic updates!

---

### Method 2: Manual Download (Vencord / BetterDiscord / Vesktop)
1. Download [`fameboyq-violet.theme.css`](https://raw.githubusercontent.com/Fameboyq/vencord-violet-theme/main/fameboyq-violet.theme.css).
2. Open your Discord Theme folder:
   * **Vencord:** Settings ➔ Themes ➔ **Open Themes Folder**
   * **BetterDiscord:** Settings ➔ Themes ➔ **Open Themes Folder**
3. Drop `fameboyq-violet.theme.css` into that folder.
4. Enable the theme in Discord settings.

## 🇷🇺 Инструкция на русском

### Способ 1: Быстрое подключение по ссылке (Vencord / Vesktop)
1. Откройте настройки Discord (шестеренка внизу).
2. Перейдите во вкладку **Темы** (в блоке Vencord).
3. В поле **Ссылки на темы** (Theme Links) вставьте:
   ```text
   https://raw.githubusercontent.com/Fameboyq/vencord-violet-theme/main/fameboyq-violet.theme.css
   ```
4. Нажмите Enter. Тема применится моментально и будет обновляться автоматически.

---

### Способ 2: Скачивание файла в папку тем
1. Скачайте файл [`fameboyq-violet.theme.css`](https://raw.githubusercontent.com/Fameboyq/vencord-violet-theme/main/fameboyq-violet.theme.css).
2. В настройках Vencord или BetterDiscord нажмите кнопку **«Открыть папку тем»**.
3. Закиньте скачанный `.css` файл в эту папку.
4. Включите тумблер темы в списке.
